# GlanceHold

GlanceHold 是一个轻量级本地工具，可以在你移开视线、不再看向屏幕时自动暂停/取消倍速播放视频，并在你重新看向屏幕后自动恢复播放/恢复倍速播放。

它不依赖云端服务，也不试图进行精确的眼动追踪。GlanceHold 使用普通 2D 摄像头实时估计头部朝向：当检测到人脸离开画面，或头部偏转角度超过设定阈值时，当前视频会自动暂停/取消倍速播放；当你重新面向屏幕并保持短暂稳定后，视频会自动继续播放/恢复倍速播放。

这个项目适合用于网课、长视频、教程、讲座回放等场景。它的目标不是判断眼睛正在注视屏幕上的哪个具体位置，而是提供一种实用、轻量、注重隐私的注意力感知播放控制方式。

所有视觉处理都计划在本地设备上完成。摄像头画面不会被上传、保存或发送到任何远程服务。

核心功能：

* 使用普通摄像头进行实时头部朝向估计
* 当用户离开画面或明显转头时自动暂停视频/取消倍速播放
* 当用户重新面向屏幕时自动恢复播放/恢复倍速播放
* 通过防抖逻辑避免频繁误暂停或误操作
* 尊重用户的手动暂停状态，避免不必要的自动播放
* 支持配置头部偏转阈值、离开判定时长和恢复播放延迟
* 面向本地播放器和网页视频场景设计

GlanceHold 的核心想法很简单：

当你移开视线，视频暂停；当你回来，播放继续。
